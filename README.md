# 醃製配方管理師｜MarinadeMaster

iPhone App + Web 管理後台。目標：配方版本管理、重量換算、生產批次、原料庫存、批次成本、照片與 PDF 報表。

## 現況
- Repository 已建立，預設分支 `main`，目前為空白專案。
- 本次先提交可在手機／桌面瀏覽器操作的 Web MVP（PWA 基礎）。
- iOS 原生 App、雲端登入／同步、正式資料庫與部署尚待後續階段。
- MVP 使用瀏覽器 localStorage；請定期匯出 JSON 備份。不同裝置不會自動同步。

## 原始配方資料原則
1. 歷史配方為不可覆寫的原始版本；修改只能複製建立新版本。
2. 生產批次固定保存當時配方快照。
3. 未取得的資料不補猜；原始紀錄文字原樣註明。
4. 檸檬雞 2026-10-05 配方明確註記「醃料階段沒有加水」。
5. 紅麴豆乳雞甜菜根粉版 18kg 配方中「磷酸鈉 5g 或林寶粉」維持原始歧義，不替使用者決定。

## 已匯入資料
- 紅麴豆乳雞－甜菜根粉版：18kg 基準，濕料與乾料／粉漿材料依已知紀錄匯入。
- 檸檬雞－熟黃豆粉版：17kg 翅腿基準，2026-10-05 原始紀錄，未加水。

## 本機執行
直接以瀏覽器開啟 `index.html`。若使用 PWA 安裝，需部署至 HTTPS 網站。
