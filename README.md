# 醃製配方管理師｜MarinadeMaster

以 iPhone 瀏覽器與桌面瀏覽器為第一階段操作介面，後續規劃原生 iOS App 與雲端管理後台。

## 目前 Web MVP 功能
- 兩筆已知歷史配方資料與原始備註。
- 配方新增／編輯器：可新增群組、原料、用量及 g／kg 單位；編輯一律另存新版本，保留舊版。
- 配方複製另存版本、版本原料差異比較。
- 依雞肉重量換算各原料用量。
- 建立生產批次，保存配方版本與批次配方快照。
- 退冰、醃製、裹粉、完成等製程時間紀錄。
- 生產批次照片：選取／拍攝照片、壓縮成 JPEG、加入備註、檢視與刪除；照片隨 JSON 備份。
- 原料庫存建立、採購進貨歷史、供應商紀錄與庫存異動流水帳。
- 採購退貨：依原採購單價沖回庫存價值，限制退貨量不得超過未退數量及現有庫存。
- 實際盤點：記錄帳面數量、實盤數量與差異，不任意改動加權平均單價。
- JSON 匯入會驗證庫存與採購欄位，並相容舊版備份缺少採購／流水帳陣列的情況。
- 進貨自動以加權平均法更新庫存成本，保留每次採購的數量、單價及日期。
- 生產完成前彙總同名原料需求、檢查庫存後一次扣料，避免重複配方行造成部分扣庫存。
- 批次完成時保存原料單價快照與成本；歷史批次不會因後續進貨價格改變而被重算。
- 原料成本支援 g／kg 換算，缺少單價時標示待補，不猜測成本。
- 批次報表列印／另存 PDF、JSON 備份與匯入。

## 重要限制
- 資料目前儲存在單一瀏覽器的 localStorage，不是雲端資料庫；不同裝置不會自動同步。
- 照片目前壓縮後以 base64 儲存在瀏覽器 localStorage，會受瀏覽器儲存容量限制；尚未使用雲端物件儲存。
- 採購進貨、退貨與盤點目前採提示視窗操作；完整採購表單、供應商主檔及多層權限仍待後續優化。
- 尚未完成多人登入、雲端同步、正式部署、完整原生 iOS App、TestFlight 或 App Store 上架。
- 配方編輯器與照片功能已提交程式碼並完成靜態內容檢查；尚未宣稱完成真實瀏覽器／iPhone 實機測試。
- 使用前請先匯出 JSON 備份；清除瀏覽器網站資料可能導致本機資料遺失。

## 原始配方資料保護
1. 歷史配方不覆寫；修改以複製方式另存新版本。
2. 生產批次保存建立當時的配方快照，後續配方變更不應改寫舊批次。
3. 不自行推測缺失數據。
4. 檸檬雞 2026-10-05 配方明確註記「醃料階段沒有加水」。
5. 紅麴豆乳雞甜菜根粉版 18kg 配方中「磷酸鈉 5g 或林寶粉」維持原始歧義，不替使用者決定。

## 已匯入歷史資料
- 紅麴豆乳雞－甜菜根粉版：18kg 基準，濕料與乾料／粉漿材料依已知紀錄匯入。
- 檸檬雞－熟黃豆粉版：17kg 翅腿基準，2026-10-05 原始紀錄，醃料階段未加水。

## 本機使用
可直接以瀏覽器開啟 `index.html`。若要以 PWA 安裝，需先部署至 HTTPS 網站。
